    Router

    wybthon.router¶

    router ¶

    Routing and the data layer, as in Solid Router 2.0.

    Import it from wybthon.router:

    • Routes. create_router takes a tree of Routes (or file_routes(), one module per page) and returns the router; call it to render. Plain <a href> links navigate within the app. Outlet renders a layout's matched child.
    • Reading the URL. use_params, use_search_params, use_location, use_route_matches, and use_link_state; navigate goes somewhere.
    • Data. query wraps an async read so calls are deduplicated and refetch on revalidate; form_action makes an action a form can post to, even before Python has booted, and use_submissions reads its history.
    from wybthon import FormData, component, create_memo, html, server_function
from wybthon.router import Route, RouteProps, create_router, form_action, query


@query
@server_function
async def get_user(user_id: int) -> User:
    return await db.users.get(user_id)


@form_action
@server_function
async def rename(user_id: int, form: FormData) -> None:
    await db.users.rename(user_id, form["name"])


@component
def Profile(props: RouteProps):
    user = create_memo(lambda: get_user(int(props.params["id"])))
    return html(t'''
      <h1>{user().name}</h1>
      <form action={rename.bind(user().id)} method="post">
        <input name="name"><button>Rename</button>
      </form>
    ''')


router = create_router([Route("/", Home), Route("/users/:id", Profile), Route("*404", NotFound)])

    Path matching (resolve) needs no browser, so it also runs in tests, tools, and on the server.

    Query(fn: Callable[P, Awaitable[R]], key: str)

    Route dataclass ¶

    Route(path: str = '', component: Any = None, children: list[Route] = list(), preload: Callable[[PreloadArgs], Any] | None = None)

    A route: a path pattern, the component it shows, and nested routes.

    Patterns are literals, :name parameters, optional :name? parameters, and a final *name catch-all ("*404" matches anything). A child's path continues its parent's, and a route with children is a layout: it renders when one of its children matches, with that child as its children prop (and as Outlet()). A route with no component renders its children directly.

    component Any

    children list[Route]

    Nested routes.
    preload Callable[[PreloadArgs], Any] | None

    Called with PreloadArgs when the route is about to show, or when a link to it is preloaded. Warm the route's queries here. Its result, once any awaitable it returns resolves, is the component's data.

    query ¶

    query(fn: Callable[P, Awaitable[R]], key: str | None = None) -> Query[P, R]

    query(key: str) -> Callable[[Callable[P, Awaitable[R]]], Query[P, R]]

    query(fn: Any, key: str | None = None) -> Any

    Wrap an async read so calls are deduplicated and can be revalidated by key.

    Use it as a decorator, bare or with a key, or call it with a function and a key, as in Solid:

    @query
@server_function
async def get_user(user_id: int) -> User:
    return await db.users.get(user_id)


@component
def Profile(props: RouteProps):
    user = create_memo(lambda: get_user(int(props.params["id"])))
    return html(t"<h1>{user().name}</h1>")

    A query:

    1. dedupes calls on the server for the lifetime of the request;
    2. in the browser, reuses a result for five seconds after it arrives, so a link's preload and the page it opens share one fetch;
    3. refetches, in every memo that read it, when revalidate names its key, or when a mutation completes (see server_function).

    A server function wrapped in a query is called with GET.

    Parameters:

    Name Type Description Default
    fn Any

    The async function to wrap (or, used as @query("key"), the key).

    		 required
    key str | None

    The query's key. Defaults to the server function's id, or the function's module and qualified name.

    		 None

    revalidate ¶

    revalidate(keys: str | Query[..., Any] | Iterable[str | Query[..., Any]] | None = None) -> None

    Refetch the queries whose keys start with keys (every query when omitted).

    Each memo that read a matching query runs again; a memo with a value holds it on screen until the new one lands. On the server it does nothing.

    Parameters:

    Name Type Description Default
    keys str | Query[..., Any] | Iterable[str | Query[..., Any]] | None

    A key, a Query, or several. A key matches every call whose full key starts with it, so revalidate(get_user) refetches every user.

    		 None

    navigate ¶

    navigate(path: str, *, replace: bool = False, scroll: bool = True) -> None

    Go to path within the app, or load it when it's on another origin.

    Relative paths resolve against the current URL. Back and forward restore scroll positions; an ordinary navigation scrolls to the hash's target, or to the top, once the destination is on screen. A path starting with / is a full path: the router's base isn't added. A no-op while rendering on the server.

    create_router ¶

    create_router(routes: list[Route], *, base: str = '', preload_links: bool = True) -> Router

    Create the app's router from its route tree, as Solid Router 2.0's createRouter does.

    The router follows plain <a href> links: a click on a same-origin link under the base path navigates with the History API instead of loading a page. Clicks with a modifier key, links with a target, download, or rel="external", and other origins are left to the browser. With preload_links, resting the pointer on a link (or focusing it) preloads its route's code and data.

    router = create_router([
    Route("/", Home),
    Route("/users/:id", User, preload=lambda args: get_user(int(args.params["id"]))),
    Route("*404", NotFound),
])

def app():
    return router(root=Shell)

    What's in this module¶

    Routing and the data layer, as in Solid Router 2.0. Import it from wybthon.router; these names aren't re-exported from wybthon. Only a change in which route matches remounts a route; param and search changes flow into the mounted component as prop updates.

    Name Description
    create_router create_router(routes, *, base="", preload_links=True): the app's Router. Call it to render: router(), or router(root=Shell) with a root layout.
    Route Route(path, component=None, children=[], preload=None). Patterns: :id, :id?, and a final *name catch-all.
    RouteProps Props for a route's component: params, search, data, and children.
    PreloadArgs What a route's preload receives: params, location, and intent.
    Outlet The matched child route, inside a layout.
    file_routes file_routes("app.routes"): a route tree from a package of route modules.
    navigate navigate(path, *, replace=False, scroll=True).
    use_params Tracked accessor for the path parameters.
    use_search_params (search, set_search): the SearchParams and a merging setter.
    use_location The URL: .path, .search, .hash, .query, .href, each a tracked read. url is the raw accessor.
    use_route_matches Tracked accessor for the matched routes, root to leaf.
    use_link_state use_link_state(href, *, end=False): .active() and .current() accessors for styling links.
    preload_route Preload a route's code and data from code.
    query, revalidate Deduplicated, revalidating reads.
    form_action, use_submissions Actions a form posts to, and their settled submissions.
    resolve, RouteSpec Matching without a browser.

    Links are plain <a href> elements: the router follows same-origin clicks under its base path and leaves modifier-key clicks, target, download, rel="external", and other origins to the browser.

    from wybthon import ParentProps, component, html
from wybthon.router import Route, RouteProps, create_router, use_link_state


@component
def Home():
    return html(t"<h1>Home</h1>")


@component
def User(props: RouteProps):
    return html(t"<h1>User {props.params['id']} (tab={props.search.get('tab', 'info')})</h1>")


@component
def NotFound():
    return html(t"<h1>Not found</h1>")


@component
def Shell(props: ParentProps):
    users = use_link_state("/users")
    return html(t"""
      <nav><a href="/">Home</a> <a href="/users/1?tab=posts" class={"active" if users.active() else ""}>Ada</a></nav>
      {props.children}
    """)


router = create_router([Route("/", Home), Route("/users/:id", User), Route("*404", NotFound)])


def app():
    return router(root=Shell)
